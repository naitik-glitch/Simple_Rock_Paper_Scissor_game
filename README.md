# Rock Paper Scissor Game

A simple Rock Paper Scissor game made using Python.

## How It Works

- Player chooses:
  - Rock
  - Paper
  - Scissor
- Computer randomly selects one option.
- The program compares both choices and shows:
  - Win
  - Lose
  - Draw

- Functions
- Lists
- Conditionals (`if`, `elif`, `else`)
- Loops (`while`)
- User Input
- Random Module
